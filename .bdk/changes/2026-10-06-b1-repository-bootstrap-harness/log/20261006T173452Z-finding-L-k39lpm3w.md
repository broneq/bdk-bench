design.md:74 says "T43 defaulted to 5 and rejected `--runs 1`". In `cli.ts` at `825455dd`, the run options set `runs: suite === "regression" ? 1 : 5`. The `--runs` flag then rejects any integer below 2, for every suite including regression. Decision L-0aefj6ru repeats "T43 default of 5 runs".

This does not change what B1 builds: one run by default, `--runs` from 1. It is still a false statement about the source code, raised as observation L-kzgh1mvy in attempt 2 and not fixed.
