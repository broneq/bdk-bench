Why it matters: a regression in the temp-directory cleanup or the 1/5-run loop is only seen when the CLI runs, and the plan lists check among the part's success measures.

Suggested fix: add a test that injects nothing but spies on nothing real: run check() against the repository root when promptfoo is installed, or skip it and keep the CLI check as the covering signal and state that in the test file.
